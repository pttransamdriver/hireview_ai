## 🎯 QUICK STEPS

### 1️⃣ Create Vercel Account (1 min)

```
Go to: https://vercel.com
Click: "Sign Up"
Choose: "Continue with GitHub"
Authorize: Vercel access
Done! ✅
```

### 2️⃣ Import Repository (1 min)

```
Dashboard → "Add New..." → "Project"
Select: Your hireview_ai repository
Click: "Import"
Done! ✅
```

### 3️⃣ Add Environment Variables (2 min)

Click "Environment Variables" and paste:

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_anon_key_here
SUPABASE_SERVICE_ROLE_KEY=your_service_role_key_here
NEXT_PUBLIC_APP_URL=https://hireviewai.vercel.app
NODE_ENV=production
```

### 4️⃣ Deploy (1 min)

```
Click: "Deploy"
Wait: 2-5 minutes for build
Done! ✅
```

### 5️⃣ Test (Optional)

```
Visit: https://hireviewai.vercel.app
Test: All pages and features
Done! ✅
```
