# Hire View AI - AI Context File

## Project Overview
Hire View AI is a Next.js-based AI-powered interview screening platform that streamlines the hiring process by allowing candidates to record video responses to interview questions, which are then analyzed and ranked by AI.

## Tech Stack
- **Framework**: Next.js 16.0.1 with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Database**: Supabase (PostgreSQL)
- **Authentication**: Supabase Auth
- **Payments**: Stripe
- **AI**: OpenAI API
- **Video Storage**: Cloudinary
- **State Management**: Zustand
- **UI Components**: Custom components with class-variance-authority

## Key Features
1. **Dual User Types**: Companies (employers) and Candidates (job seekers)
2. **AI-Powered Screening**: Video interview analysis and candidate ranking
3. **Subscription Tiers**: Basic, Pro, Unlimited plans
4. **Video Interviews**: Record responses to custom questions
5. **Smart Ranking**: AI scores based on clarity, confidence, relevance, time compliance

## Database Schema
### Core Tables:
- `users` - User profiles (extends Supabase auth)
- `companies` - Company information and subscription details
- `jobs` - Job postings with status tracking
- `interview_questions` - Custom questions per job (30-180 second time limits)
- `applications` - Candidate applications with ranking scores
- `interview_responses` - Video responses with transcriptions
- `rankings` - AI analysis scores (clarity, confidence, relevance, time compliance)
- `payments` - Stripe payment tracking

## Key Design Decisions
- **Mobile-first responsive design**
- **Primary color**: Blue (#1A56DB)
- **Secondary color**: Emerald (#10B981)
- **Row Level Security (RLS)** enabled for data protection
- **Server-side rendering** with Next.js App Router
- **Type-safe database queries** with TypeScript
