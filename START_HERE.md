## 🆘 Troubleshooting

### npm install hanging?
```bash
rm -rf node_modules package-lock.json
npm install
```

### Port 3000 in use?
```bash
npm run dev -- -p 3001
```

### TypeScript errors?
- Run `npm install` again
- Delete `.next` folder
- Restart IDE

### Supabase connection issues?
- Check `.env.local` credentials
- Verify Supabase project is active
- Check network connectivity
